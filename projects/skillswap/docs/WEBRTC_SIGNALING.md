# SkillSwap — WebRTC Signaling Specification

## Signaling Protocol Flow (Socket.IO)

```
User A (Caller)              Signaling Server (Flask-SocketIO)              User B (Callee)
      │                                       │                                    │
      │ ──── join_room({ room: ID }) ───────> │                                    │
      │                                       │ <─── join_room({ room: ID }) ───── │
      │                                       │ ── user_joined ──────────────────> │
      │                                       │                                    │
      │ ──── RTCPeerConnection (Local Stream) │                                    │
      │ ──── createOffer() ──────────────────>│                                    │
      │ ──── emit('offer', SDP) ─────────────>│ ── emit('offer', SDP) ───────────> │
      │                                       │ ── setRemoteDescription() ──────── │
      │                                       │ ── createAnswer() ──────────────── │
      │ <─── emit('answer', SDP) ─────────────│ <─ emit('answer', SDP) ─────────── │
      │ ──── setRemoteDescription()           │                                    │
      │                                       │                                    │
      │ ──── emit('candidate', ICE) ─────────>│ ── emit('candidate', ICE) ────────> │
      │ <─── emit('candidate', ICE) ──────────│ <─ emit('candidate', ICE) ──────── │
      │                                       │                                    │
      │ ═══════════════════ DIRECT P2P MEDIA (SRTP/STUN) ═════════════════════════ │
```

## Features & Implementation
- **Room Isolation:** Socket.IO rooms segregate signaling messages so candidate offers and answers are only routed to the active conversation partner.
- **ICE Candidate Exchange:** Dynamic Trickle ICE handling forwards network route discovery candidates asynchronously as they are generated by the browser.
- **Media Controls:** Live track muting and camera toggling without renegotiation disruption.
