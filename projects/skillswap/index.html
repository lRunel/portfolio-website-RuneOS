SkillSwap

SkillSwap replaces paywalled tutoring with mutual skill exchange. Users declare what they know and what they want to learn. The matchmaking engine finds reciprocal peers and boots an in-browser WebRTC video call room instantly without third-party services.

Architecture & Real-Time Signaling

Signaling uses Flask-SocketIO to coordinate session initiation (SDP offer/answer and Trickle ICE candidates), while audio and video media stream directly peer-to-peer over SRTP with zero server bandwidth overhead.

Technical Highlights

1. Automated Relational Matchmaking

Cross-joins the User and Skill tables to filter reciprocal matches without external recommendation servers or high latency.

2. In-Browser WebRTC Peer Media

Utilizes native RTCPeerConnection APIs to establish low-latency, encrypted audio and video connections directly between peers.

3. Isolated Signaling Rooms

Socket.IO room segregation guarantees privacy by broadcasting signaling negotiations only to users inside that specific video call session.

Known Limitations

  • Requires public STUN/TURN servers for Symmetric NAT traversal across restrictive corporate firewalls
  • Mesh topology currently connects 2 peers per call; multi-party calling would require SFU / MCU infrastructure
  • Matchmaking scoring is binary (exact string match); semantic embedding search is a future upgrade
