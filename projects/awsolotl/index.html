AWSolotl (Project Lockstep Recall)

The Brake, Not Just the Driver — An immutable, multi-stage control plane that checks an AI agent's proposed fixes against Cedar policies before they touch AWS, and records every decision in an append-only audit log.

Autonomous AI agents are transforming DevOps, but in enterprise production, nobody lets an AI agent press the button without verification. Hallucinated parameters, missing institutional memory, or broad static permissions cause catastrophic outages. AWSolotl solves this by providing The Brake: an independent verification plane that validates plans before execution, bounds blast radii with temporary STS credentials, monitors execution in real time, and cryptographically audits every decision.

The Three Planes Architecture

Core Thesis: Diagnosis is a demo. Safety is the product. Cut the brain, never cut the brake.

AWSolotl completely decouples untrusted LLM decision-making from deterministic execution and control. Even if the diagnostic LLM is compromised or hallucinates, the control plane mathematically guarantees safety invariants cannot be violated.

The 5 Gates of Control ("The Brake")

GATE 1
Authority & Schema (~5ms)
Validates against rigid JSONSchema, verifies typed tool arguments, and requires valid short-lived capability tokens.
GATE 2
Formal Policy Proof (~180ms)
Evaluates against AWS Cedar policies and frozen invariants (INV-01 to INV-12), including Black Friday change freezes and database protection.
GATE 3
Radius Verification (~300ms)
Simulates the plan against live AWS topology. Confirms that affected services match declared blast radius boundaries.
GATE 4
Risk Scoring & Ladder (~50ms)
Computes multi-factor risk score. Dispatches autonomous execution for low risk (L1/L2) or blocks for human confirmation (L0).
GATE 5
Active Watchdog (~100ms)
Watches post-execution SLOs in real time. Detects runaway remediation loops and triggers automated rollback if degradation persists.

Technical Highlights

1. Linear-Gaussian SCM L2 Residual Scoring

Standard correlation metrics fail in microservice call graphs because latency cascades downstream. AWSolotl fits a linear regression of each node's latency against its callers and scores the residual deviation. Downstream nodes have residuals near zero, isolating the true root cause with >= 85% Top-3 accuracy on the PetShop benchmark.

2. Permutation Falsification Honesty Gate

A 200-shuffle two-sample permutation test evaluates the top causal candidate. If the empirical p-value exceeds 0.05, the system sets abstained: true, which structurally forbids destructive actions via Cedar Invariant INV-03.

3. Dynamic STS IAM Credential Broker

Remediation actions never use permanent administrator keys. The broker generates temporary STS session tokens scoped with dynamic session policies allowing only the specific ARN, action, and 900-second window required for the step.

4. Tamper-Proof Cryptographic Ledger

Every decision, policy proof, and execution result is hashed into a SHA-256 hash chain stored in DynamoDB and mirrored to S3 with Object Lock in Compliance mode (WORM storage) for regulatory auditability.

Known Limitations

  • X-Ray traces must be enabled with 100% sampling during active incident windows to ensure accurate SCM graph reconstruction
  • Cedar policy evaluations require sub-millisecond local policy store caching for high-frequency gates
  • Permutation tests require a minimum baseline sample window of 30 historical observation points
  • Multi-region blast radius containment currently assumes single-region failover partitions
